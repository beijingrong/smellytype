# SmellyType agent entry point

For installation requests, read README.md and docs/INSTALL.md, then perform the installation. This is a standalone cloud dictation application derived from Voxtype; do not install Voxtype as its prerequisite. First release targets Omarchy with Quickshell and Hyprland Lua bindings.

Keep API keys out of chat, command arguments and source control. Reuse a user's existing Doubao key only for their requested migration. Do not interrupt recording or final recognition. Preserve original copyright and third-party notices. Keep commits signed, matching the inherited upstream contribution requirement.

Use scripts/install.py for staging and optional activation/migration. Inspect the rollback snapshot before restoring it over later user edits. Do not publish or send marketplace submissions merely because installation is requested. The first release retains inherited local-engine implementation internally; it is not a ground-up rewrite and supports Doubao only as a product.
